# 大模型数据集合成差分隐私应用标准流程使用说明

## 概述

本项目实现了一个完整的差分隐私（Differential Privacy, DP）标准流程，专门用于大模型数据集合成场景。该框架提供了从数据预处理到合成数据生成、隐私分析和质量评估的端到端解决方案。

## 核心特性

### 🔒 隐私保护
- **严格的差分隐私保证**：支持 (ε,δ)-差分隐私
- **隐私预算管理**：自动追踪和分配隐私预算
- **多种噪声机制**：高斯噪声、拉普拉斯噪声、指数噪声

### 🎯 数据合成方法
- **高斯合成**：基于私有统计量的快速合成
- **DP-GAN**：差分隐私生成对抗网络
- **可扩展架构**：易于添加新的合成方法

### 📊 质量评估
- **统计相似性**：均值、方差、相关性分析
- **效用保持**：下游任务性能评估
- **隐私风险**：成员推理攻击风险分析

## 快速开始

### 基本使用示例

```python
from 差分隐私 import DPConfig, DifferentialPrivacyPipeline
import numpy as np

# 1. 配置差分隐私参数
config = DPConfig(
    epsilon=1.0,        # 隐私预算
    delta=1e-5,         # 放松参数
    noise_multiplier=1.1,
    batch_size=64,
    sampling_rate=0.01
)

# 2. 创建流程实例
dp_pipeline = DifferentialPrivacyPipeline(config)

# 3. 准备原始数据
original_data = np.random.randn(1000, 10)  # 示例数据

# 4. 运行合成流程
results = dp_pipeline.run_synthesis_pipeline(
    original_data=original_data,
    n_synthetic=800,
    method='gaussian',
    output_path='./output'
)

# 5. 获取结果
synthetic_data = results['synthetic_data']
quality_report = results['report']
```

## 详细配置说明

### DPConfig 参数

| 参数 | 说明 | 默认值 | 建议范围 |
|------|------|--------|----------|
| `epsilon` | 隐私预算，值越小隐私保护越强 | 1.0 | 0.1-10.0 |
| `delta` | 放松参数，通常设为很小值 | 1e-5 | 1e-6-1e-4 |
| `noise_multiplier` | 噪声倍数 | 1.1 | 0.5-2.0 |
| `max_grad_norm` | 梯度裁剪阈值 | 1.0 | 0.5-2.0 |
| `sensitivity` | 敏感度参数 | 2.0 | 1.0-5.0 |

### 合成方法选择

#### 1. 高斯方法 (`method='gaussian'`)
- **适用场景**：连续数值数据
- **优点**：计算快速，理论保证强
- **缺点**：假设数据符合高斯分布

```python
results = dp_pipeline.run_synthesis_pipeline(
    original_data=data,
    n_synthetic=800,
    method='gaussian'
)
```

#### 2. DP-GAN方法 (`method='gan'`)
- **适用场景**：复杂数据分布
- **优点**：生成质量高，适应性强
- **缺点**：训练时间长，参数调节复杂

```python
results = dp_pipeline.run_synthesis_pipeline(
    original_data=data,
    n_synthetic=800,
    method='gan'
)
```

## 最佳实践

### 1. 隐私预算分配策略
```python
# 推荐的预算分配比例
total_epsilon = 2.0
preprocessing_budget = total_epsilon * 0.1  # 10%
synthesis_budget = total_epsilon * 0.8      # 80%
evaluation_budget = total_epsilon * 0.1     # 10%
```

### 2. 参数调优建议
- **高隐私需求**：ε ≤ 0.5, δ ≤ 1e-6
- **平衡模式**：ε = 1.0-2.0, δ = 1e-5
- **高效用需求**：ε ≥ 5.0, δ = 1e-4

### 3. 数据预处理
```python
# 推荐的预处理流程
preprocessor = DataPreprocessor(config)

# 1. 标准化
data = preprocessor.normalize_data(raw_data)

# 2. 裁剪异常值
data = preprocessor.clip_data(data, -3, 3)

# 3. 子采样（如果数据量很大）
if len(data) > 10000:
    data, _ = preprocessor.subsample_data(data)
```

## 故障排除

### 常见问题

1. **内存不足**
   ```python
   # 解决方案：减少批处理大小
   config.batch_size = 32
   ```

2. **隐私预算超支**
   ```python
   # 解决方案：增加总预算或减少操作
   config.epsilon = 2.0
   ```

3. **合成质量差**
   ```python
   # 解决方案：调整噪声参数
   config.noise_multiplier = 0.8
   config.sensitivity = 1.0
   ```
