# 提示词越狱防护全流程说明

## 🎯 核心防护原理

基于您的要求文档，我们实现了一个**多层防护**的安全系统，核心思想是：

> **服务端锁定规则 + 输入清洗隔离 + 输出独立审核**

## 🏗️ 系统架构

```
用户输入 → 输入清洗 → 快速检测 → 深度检测 → AI模型 → 输出审核 → 安全回复
    ↓         ↓        ↓        ↓       ↓       ↓        ↓
  长度检查  特殊字符  敏感词库  ML分类器  生成内容  泄露检测  审计日志
```

## 📋 完整防护流程

### 第一层：服务端规则锁定
- ✅ **不可覆盖**：安全策略写在服务器端配置，用户无法修改
- ✅ **系统保护**：防止指令覆盖、角色注入、系统提示词攻击
- ✅ **访问控制**：API密钥、频率限制、用户权限管理

### 第二层：输入预处理清洗
```python
# 移除控制字符和隐写字符
cleaned = re.sub(r'[\x00-\x1f\x7f-\x9f]', '', text)
cleaned = re.sub(r'[\u200b-\u200f\u2060\ufeff]', '', cleaned)
```
- 🧹 **格式清洗**：移除控制字符、零宽字符、异常编码
- 📏 **长度限制**：防止超长输入导致的DoS攻击
- 🔍 **预处理**：标准化文本格式，便于后续检测

### 第三层：分级安全检测

#### 3.1 快速检测（轻量级，<5ms）
```python
# 敏感词黑名单
blocked_keywords = ["越狱", "忽略指令", "制作炸弹"]

# 危险模式匹配
dangerous_patterns = [
    r"扮演.*角色|roleplay",
    r"忽略.*指令|ignore.*instruction"
]
```

#### 3.2 深度检测（仅对可疑内容，<100ms）
```python
# 越狱指令识别
jailbreak_indicators = [
    "忽略之前的指令", "重新开始", "新的角色"
]

# 系统攻击检测  
if "AI" in text and "修改" in text:
    return DANGEROUS
```

### 第四层：AI模型调用
- 🤖 **隔离调用**：AI模型在受控环境中运行
- ⏱️ **超时保护**：防止模型调用时间过长
- 🔄 **重试机制**：异常情况下的降级处理

### 第五层：输出安全审核
```python
# 敏感信息泄露检测
system_leak_patterns = [
    r"我是.*开发的|developed by",
    r"系统提示.*|system prompt",
    r"训练.*数据|training.*data"
]

# 个人隐私信息检测
personal_info_patterns = [
    r"\d{15,18}",  # 身份证号
    r"1[3-9]\d{9}",  # 手机号
]
```

### 第六层：审计日志记录
```python
log_entry = {
    "timestamp": time.time(),
    "user_id": user_id,
    "input_risk": "suspicious", 
    "output_risk": "safe",
    "blocked": False
}
```

## ⚡ 性能优化策略

### 1. 分级过滤（先快后慢）
- 先执行毫秒级的正则匹配
- 只有可疑内容才触发重量级ML检测
- 大部分正常请求走快速路径

### 2. 缓存与去重
```python
# 输入哈希缓存
text_hash = hashlib.md5(text.encode()).hexdigest()
if text_hash in self.cache:
    return self.cache[text_hash]
```

### 3. 并行化处理
- 非阻断检查放到后台执行
- 批处理提升吞吐量
- 多Worker并发处理

### 4. 早退出机制
```python
# 高置信度立即决策
if confidence > 0.95:
    return BLOCK
elif confidence < 0.3:
    return SAFE
```

## 🛡️ 安全策略配置

### 风险等级定义
- **SAFE** (0-0.3)：正常内容，直接放行
- **SUSPICIOUS** (0.3-0.7)：可疑内容，触发深度检测  
- **DANGEROUS** (0.7-0.9)：危险内容，拒绝处理
- **BLOCKED** (0.9-1.0)：极危险，直接阻断
